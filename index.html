Welcome to OpticSite

Your clinic assistant by OpticUnity

Program Made Possible by Claude (Sonnet 4.6) & Grock

OpticSite is a standalone offline Electronic Medical Records system

Program designed for small optometry clinics.


All data is stored locally on this device. No internet connection is required.


This is a beta release. Features are still being developed and improved.

Disclaimer

By continuing, you acknowledge the following:


• This program is intended for use by a licensed optometrist or under the supervision of one, in accordance with Republic Act 8050 (Revised Optometry Law of the Philippines).


• OpticSite is currently in beta. While core functions are stable, you may encounter occasional bugs. Please report any issues to the developer.


• All patient data is stored locally on this device only. The developer is not responsible for any data loss. Regular backups are strongly recommended.

Guide

This program offers EMR & CRM system for Small Opticals

EMR - Electronic Medical Record

CRM - Customer Relationship Management

Currently on its Beta stage

Final Product will be a standalone offline version

Meaning, Expect some limitations such as:

-Not being online (cloud system backups)

-Inability to be used in multiple devices at once

-This makes the use of EMR and CRM a bit hassle, for high volume patients use

-Such scenario where a receptionist cannot record the next patient/customer,

'Cause the program is currently being used for eye checkup

Then again, the target users of this program are small clinics that cater small volume of patients

Which does not need the use of multiple devices and online functions.

The core function of EMR and CRM is now complete

EMR Features includes:

Creating Customer and Patient Record

Creating Prescription Via: Eye exam, Copy Rx (spectacle & contact lens)

Viewing, Editing and Deleting of Patient Records

Viewing, Editing and Deleting of Prescriptions

Generation of draft Certificate

CRM Features includes:

POS System

Creating Sales Order

Creating Job Order

Printing Reciept

Printing Job Order

Viewing Sales History

Data Management System

Export and Import of clinic saved data (cross-platform available)

Features still on development:

A downloadable offline Windows Version

Additional EMR features (Graph for AR and VT7, for progression reference; UI polishing)

System Flow

Creating customer and patient record

Creating prescription for the patient

View, Edit, Delete of records

Generation of Certificates

Creating sales and job order

Printing sales reciept and job order

Where are the data stored?

For Web Browser - It's locally saved in your web browser

Be careful on clearing your web browser's cache as it will permanently delete all records.

Clinic Data

About Your Data

All your records are stored locally in a single JSON file on this computer.

Default save location:

C:\Users\YourName\AppData\Roaming\com.opticunity.opticsite\

Data Migration

You can transfer your clinic data to a new device or even migrate to web browser platform seamlessly.

You can do this by Exporting and Importing it to your desired location (Instructions below).

How to Export

Click Export Save File below and the program will download a .JSON file.

Choose where you wish to save your file and store it (USB drive, Google Drive, OneDrive, etc.).

Rename the file if needed, the contents are what matter, not the filename.

JSON is a versatile file format widely used specifically in storing data.

About Your Data

All your records are stored in your browser's local storage of this device.

Browser storage can be cleared by the browser itself (clearing site data, cache wipes, etc.), exporting your save file regularly for backup is strongly advised.

Data Migration

You can transfer your clinic data to a new device or even migrate to windows platform seamlessly.

You can do this by Exporting and Importing it to your desired location (Instructions below).

How to Export

Click Export Save File below and your browser will download a .JSON file.

Choose where you wish to save your file and store it (USB drive, Google Drive, OneDrive, etc.).

Rename the file if needed, the contents are what matter, not the filename.

JSON is a versatile file format widely used specifically in storing data.

How to Import

Click Import Save File below and select your previously exported .JSON save file.

The program will check the validity of the file and ask you for confirmation.

This will replace all current records. Export your current data first if needed.
